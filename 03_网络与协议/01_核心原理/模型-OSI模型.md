#网络通信 #状态/未完成

Open System Interconnection。便理论，没有 TCP/IP 实用。

数据的出现都是始于应用层的。

数据自应用层诞生，进行了层层封装，并最终通过物理层的线路将数据发送到了另一台设备上。

每一层都有自己的工作，同时与其上层保持着密切的联系。

物理层 - 数据链路层 - 网络层 - 传输层 - 会话层 - 表示层 - 应用层

#### 物理层的传输线路

即 传输介质。
分为 有线 和 无线。

| 介质   | 传输信号 | 典型场景        |
| ---- | ---- | ----------- |
| 双绞线  | 电信号  | 以太网、电话线     |
| 同轴电缆 | 电信号  | 有线电视、早期以太网  |
| 光纤   | 光信号  | 长距离、高带宽、抗干扰 |
| 电话线  | 电信号  | DSL 宽带、电话   |
| 电力线  | 电信号  | 电力线上网、智能家居  |

| 介质   | 传输信号  | 典型场景          |
| ---- | ----- | ------------- |
| 无线电波 | 电磁波   | WI-FI、蓝牙、蜂窝网络 |
| 微波   | 电磁波   | 微波通信、卫星       |
| 红外   | 光/电磁波 | 遥控器、红外通信      |
| 激光   | 光信号   | 自由空间光通信       |
| 卫星   | 电磁波   | 卫星通信          |
