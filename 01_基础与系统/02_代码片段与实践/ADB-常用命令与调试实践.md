### 一、端口转发

``` adb
adb forward <local> <remote>
adb reverse <remote> <local>
```
ADB 里 `local` 和 `remote` 是相对 **adb server 所在主机** 来说的。

==**谁监听、谁作为入口**。==
#### 1、反向端口转发

**reverse** `adb reverse` 把连接从 Android 设备反向转发到运行 adb 的电脑。

``` adb
adb reverse tcp:7686 tcp:7686
```

**第一个** tcp:7686 **设备端** 要监听的 TCP 端口。一定得是 设备端 端口。

**第二个** tcp:7686 **电脑端** 要转发的 TCP 端口。

==当手机/模拟器里的应用访问 localhost:7886 时，实际访问的是你电脑上监听 7686 端口的服务。

==手机访问，但实际访问的是电脑端==

#### 2、正向端口转发

**forward** `adb forward` 把连接从运行 adb 的电脑转发到Android 设备。

```adb
adb forward tcp:7686 tcp:7686
```

**第一个** tcp:7686 **电脑端** 要转发的 TCP 端口。一定得是 电脑端 端口。

**第二个** tcp:7686 **设备端** 要监听的 TCP 端口。

==电脑上访问，但实际访问的是设备端==

#### 3、区分
| 命令                        | 第一个端口  | 第二个端口  | 谁在监听 | 访问入口               | 实际目标             |
| ------------------------- | ------ | ------ | ---- | ------------------ | ---------------- |
| `adb forward tcp:A tcp:B` | 电脑端口 A | 设备端口 B | 电脑   | 电脑访问 `127.0.0.1:A` | 设备 `127.0.0.1:B` |
| `adb reverse tcp:A tcp:B` | 设备端口 A | 电脑端口 B | 设备   | 设备访问 `127.0.0.1:A` | 电脑 `127.0.0.1:B` |
