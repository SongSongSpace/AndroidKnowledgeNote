# 动态规划

面对一个会重复求解子问题的递归，怎样定义状态、写出转移，并判断能否只保留少量中间结果？动态规划（Dynamic Programming，DP）先用状态描述子问题，再复用已经求出的结果。可以从最终问题出发递归并记忆化，也可以按依赖顺序迭代求解。

## 从子问题到状态转移

1. 写清楚状态表示什么。先从直接枚举或递归中找重复计算，再选择能描述剩余约束的参数。处于同一状态的不同历史，应当有相同的后续可选操作和增量代价。若历史信息仍影响后续，就把必要信息加入状态。
2. 枚举当前状态的所有合法选择，写出转移。检查依赖是否能按某个顺序求解，例如位置递增或区间长度递增，并单独写出转移无法继续时的初始状态。
3. 写出原问题的输出。答案有时是一个状态，有时需要组合多个状态。时间取决于要计算的状态数和每个状态的工作量。后续转移只依赖最近若干状态时，可以考虑复用存储。若还要回溯具体方案，则另外确认需要保存哪些决策。

原笔记的“暴力递归 → 状态抽象 → 无后效性检验 → 空间降维”可以作为检查顺序。状态数过大时，先查能否合并等价状态，或在有依据时剪去无效状态。贪心近似需要另行说明精度，最短路径建模需要说明状态图与边的含义。核对依据见 [MIT 6.006 动态规划讲义](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/28461a74f81101874a13d9679a40584d_MIT6_006S20_lec16.pdf)。

## 例题：非空连续子数组的最大和

给定非空整数数组，从中选一个非空的连续区间，求元素和的最大值。混合摘录第 185 行只记了数列 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`，这里按与该数列匹配的 [力扣第 53 题](https://leetcode.com/problems/maximum-subarray/description/)补齐题意。

- **状态**：`dp[i]` 是必须以 `nums[i]` 结尾的非空连续子数组最大和。
- **转移**：以当前位置结尾的区间，要么只取 `nums[i]`，要么把它接到以前一位置结尾的区间。两种情况取较大值，得到 `dp[i] = max(nums[i], dp[i-1] + nums[i])`。
- **初始化**：`dp[0] = nums[0]`，从左到右计算。以 `0` 作为全局最大值的初值会让全负数组误选出空区间。
- **输出**：答案是所有 `dp[i]` 的最大值，因为最优区间可以在任意位置结束。例题依次得到 `[-2, 1, -2, 4, 3, 5, 6, 1, 5]`，最大值为 `6`，对应 `[4, -1, 2, 1]`。
- **空间优化**：下一步只用到前一个 `dp[i]`，输出只需要迄今最大值，因此可各用一个变量。扫描一次，时间 `O(n)`，额外空间 `O(1)`。

递推与非空边界见 [MIT 6.006 动态规划习题课](https://live.ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/487dc976eabd0f9bcd6a3c385203ea27_MIT6_006S20_r16.pdf)。
