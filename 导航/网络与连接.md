# 网络与连接

## 从基础学习到直连

1. 网络分层可从 [[概念与机制/网络/OSI模型|OSI 模型]] 读到 [[概念与机制/网络/TCP-IP模型|TCP/IP 模型]]。传输层的建连另见 [[概念与机制/网络/TCP三次握手|TCP 三次握手]]。
2. 地址与路径：[[概念与机制/网络/路由器|网络-路由器]] → [[概念与机制/网络/NAT|网络-NAT]] → [[概念与机制/网络/NAT穿透|网络-NAT穿透 Hole Puching 技术]]。
3. 对等连接：[[概念与机制/连接/P2P连接|架构-P2P 连接]] → [[操作与方案/连接/WebSocket信令与UDP打洞|网络-P2P直连架构（WebSocket信令与UDP打洞）]]。
4. 进入实时音视频：[[导航/RTC学习与排障|RTC 学习与排障]]，继续看信令、SDP 与媒体采集。

## 按问题查

- 信号、成帧、检错和共享信道分别该查哪里？见 [[概念与机制/网络/OSI模型|OSI 模型]]。
- 端口属于哪一层？跨网段发送时 ARP 查谁的 MAC？先看 [[概念与机制/网络/TCP-IP模型#四层和五层读法|四层和五层读法]]，再看 [[概念与机制/网络/TCP-IP模型#下一跳与地址解析|下一跳与地址解析]]。
- 排查基础连通性：[[操作与方案/连接/Ping诊断|网络-Ping命令详解]]；它不能独自证明应用层可用。
- 查局域网设备：[[导航/设备发现与投屏|设备发现与投屏]]。
- 查网络请求框架：[[概念与机制/网络/Retrofit注解映射机制|网络-Retrofit核心原理与注解映射]]，另见 [[概念与机制/并发/Kotlin协程基础|并发-协程基础]]。
